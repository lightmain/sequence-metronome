# 网页节拍器

面向 Windows 浏览器的纯前端节拍器，支持普通循环与变拍曲目序列。React + TypeScript + Vite，无需后端。音效已经随项目保存。

## 本地运行

需要 Node.js 22.12 或更新版本，以及 pnpm 11.25。依赖已安装时直接运行：

```powershell
cd E:\Casual\Metronome
pnpm dev
```

浏览器打开 http://127.0.0.1:5173/ 。固定地址和端口，以便使用同一份浏览器本地保存。首次获取项目时执行 `pnpm install --frozen-lockfile` 安装依赖。

## 功能

- 普通节拍器：拍号、BPM、首拍重音、总音量，持续循环。
- 序列节拍器：每段独立拍号与 BPM，指定开始小节，准备循环与准备一小节后进入。
- 显示整曲小节数、当前段内小节数、每拍圆角方形指示灯和当前段高亮。
- 在任意行间插入段落、删除、转换为注释、新增注释。
- 单击、复选框、Shift 连选、Ctrl 单选增减，以及拖动框选；支持多段、注释跨曲目复制粘贴。
- 每首曲目独立撤销与重做，最多保留 200 次编辑历史。
- 多曲目标签页，双击标签或 F2 重命名。
- 文本与 JSON 文件导入、导出；浏览器内直接编辑文本，解析失败给出行号与原因。
- Ctrl+S 保存当前曲目至浏览器，星号标记未保存修改，恢复已保存内容时清除星号。

## 速度与拍号

BPM 始终表示每分钟的四分音符数量。发声和拍灯以拍号分母对应的音符推进，每小节次数等于分子。

例如 BPM 120 时，4/4 每拍间隔 0.5 秒、每小节 2 秒；8/8 每拍间隔 0.25 秒、每小节同为 2 秒。

分子支持 1–32，分母支持 1/2/4/8/16/32，BPM 支持 20–400 且允许小数。第一拍以更高音调和音量提示；首版不提供分组重音。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| Enter | 停止时直接播放 |
| Space | 序列停止时进入准备循环；准备时在下一小节进入序列 |
| N | 序列停止时先准备一小节；准备时在当前小节结束后再准备一小节 |
| Backspace | 取消播放 |
| Ctrl+C / Ctrl+V | 复制选中行 / 在选定行间粘贴 |
| Ctrl+A | 选择当前曲目的全部行 |
| Delete | 删除选中行 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| Ctrl+S | 保存当前曲目 |
| F2 | 重命名当前曲目 |

普通模式下 Space 开始或停止。文字和数值输入框内保留正常编辑行为，Ctrl+S 可提交当前数值并保存。数值输入中 Enter 提交，Esc 取消。文本对话框需先点击确定再保存。

## 段落编号规则

第一段从 1 开始。非最后一段的终点由下一段起点推导；最后一段的终点可以直接修改。

悬停行间的“＋”并点击选择插入位置，再点击“新增段落”或按 Ctrl+V。未选择行间位置时，插入在所选行之后；未选择任何行时插入在曲尾。

新增段落默认一小节，继承上一演奏段落的拍号和 BPM。开头插入继承下一段；空曲目采用 4/4、120。注释不参与继承和小节计数。

插入只向后递推必要的起点。例如 `1–62 / 63 / 64–129` 在 63 小节段落前插入后成为 `1–62 / 63（新）/ 64 / 65–129`，曲尾仍为 129。连续单小节可能将递推传至曲尾，必要时延长曲目。

删除让后一段起点前移。例如删除 `1–62 / 63 / 64–129` 的中间段，结果为 `1–62 / 63–129`，后一段自己的拍号和 BPM 覆盖删除范围。转换注释采用相同规则。

删除最后一段时缩短曲尾；删除全部演奏段落后保留空曲目，禁用播放。

## 文本格式

```text
1 4/4 120
#段落注释
63 2/4 120
64 4/4 120
130
```

每个演奏段落一行，字段为“起始小节 拍号 BPM”；`#` 开头为注释。最后的 130 是结束边界，表示实际播放到 129 小节。空曲目导出为结束边界 1，可保留注释。

支持 UTF-8、Windows/Unix 换行和空行。解析失败保留原曲目及文本草稿。导入打开新标签，文本文件名作为曲目名。JSON 格式包含格式版本、曲目名称、结束边界和段落/注释行，示例见 [开发计划](DEVELOPMENT_PLAN.md)。

## 本地保存

Ctrl+S 仅保存当前曲目，不提交其他曲目未保存的修改。关闭标签仅改变当前打开的工作区，已保存曲目仍保留在曲目库；点击“打开”可以重新打开。关闭前提示未保存修改。

已保存曲目可以跨刷新和浏览器重启恢复；未保存修改首版不自动恢复。星号通过与最近一次成功保存的内容比较得到，因此撤销回保存版本会自动清除星号。导出文件不改变星号。

保存限于当前浏览器及网站来源，本地服务和 GitHub Pages 不共享。清除网站数据也会删除保存，建议导出文本或 JSON 作为备份。无痕浏览的保存会随无痕窗口关闭而清除。

## 播放

准备模式始终使用曲目第一段的拍号与 BPM，即使正式播放的开始小节位于其他段。准备小节不占正式小节编号；正式播放从指定小节第一拍开始，到曲尾完整结束时停止。

序列播放时锁定结构和参数编辑，仍可调节音量、保存和导出。切换曲目或模式会停止播放。普通模式可以实时调速，拍号变化从下一小节开始。

使用浏览器音频时钟提前安排节拍，停止时取消已安排的声音。第一版以桌面前台播放为验证目标，若浏览器或设备中断音频则停止并提示重新开始。手机适配、锁屏播放、分组重音、暂停和循环练习留待后续版本。

## 检查与构建

```powershell
pnpm test
pnpm build
pnpm preview
```

构建产物位于 `dist/`。`pnpm preview` 在 http://127.0.0.1:4173/ 预览生产构建。

Vite 使用相对资源路径，可将 `dist/` 内容部署至 GitHub Pages 项目子路径。无需部署 Node.js 服务；GitHub Pages 的构建流程应先安装依赖，再执行 `pnpm build`，发布 `dist/`。本项目尚未自动创建远端仓库或发布网站。

## 目录

- `src/model.ts`：数据校验、段落算法与导入导出。
- `src/transport.ts`：音乐时间线与音频调度。
- `src/storage.ts`：保存及撤销、重做。
- `src/App.tsx`：界面、快捷键、标签及编辑交互。
- `tests/`：编辑、解析、存储与播放测试。
- `public/sounds/`：节拍音效及许可。
